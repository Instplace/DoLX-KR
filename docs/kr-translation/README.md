# 한국어 번역 기준

이 번역본의 문체와 용어를 한쪽으로 맞추기 위해 정리한 문서입니다. 번역을 고치거나 새 버전에 맞춰 갱신할 때 참고하세요.

| 문서 | 내용 |
| --- | --- |
| [STYLE.md](STYLE.md) | 문체·표기 규칙(가장 먼저 읽을 것). 문서끼리 어긋나면 이 문서가 우선합니다. |
| [GLOSSARY-propernouns.md](GLOSSARY-propernouns.md) | 인물·장소·단체·기념일 등 고유 명사의 표준 표기 |
| [GLOSSARY-system.md](GLOSSARY-system.md) | 설정·상태·특성·선택지 등 시스템 용어 |
| [GLOSSARY-world.md](GLOSSARY-world.md) | 세계와 사물의 일반 명사 |
| [GLOSSARY-body-combat.md](GLOSSARY-body-combat.md) | 신체·성행위·전투 용어 |
| [CONVENTIONS.md](CONVENTIONS.md) | 조사 마커(`【은는】` 등), 대명사 위젯, 한글화 사전(`game/kr_js/`) 같은 기술 관례 |
| [characters/](characters/) | 인물별 말투 가이드(화계, 1인칭, 호칭, 말버릇). `_PC.md`는 플레이어 캐릭터, `_GENERIC.md`는 이름 없는 인물 |
| [STYLE-FINDINGS.md](STYLE-FINDINGS.md) | 규칙을 정할 때 근거로 삼은 기존 번역의 집계 |

## 문서에 나오는 줄임말

- **EN-old**: 원작 0.5.12.13
- **KR-old**: 기존 한국어 번역본 0.5.12.13 ([Ooo-eee/DoL_KrTranslation](https://github.com/Ooo-eee/DoL_KrTranslation))
- **EN-new**: 원작 0.5.13.8
- **KR-new**: 이 저장소(0.5.13.8에 맞춘 한국어 번역본)

규칙은 대부분 기존 번역에서 더 많이 쓰이던 쪽을 표준으로 삼은 것입니다. 표에 없는 낱말은 기존 번역에서 쓰던 표기를 찾아 그대로 따르면 됩니다.

문서에 나오는 `tm-links.tsv`, `propernouns*.tsv` 같은 파일은 정리 과정에서 쓴 집계 자료로, 저장소에는 넣지 않았습니다.
