# 문체·표기 규칙 (최종본)

기존 번역(KR-old)의 다수 관례를 표준으로 삼고, 번역 안에서 갈리던 것은 한쪽으로 정했다. 근거는 `STYLE-FINDINGS.md`(수치), `GLOSSARY-*.md`(용어), `characters/*.md`(말투), `CONVENTIONS.md`(기술 관례)에 있다.
문서끼리 어긋나면 이 문서 > 용어집 > 인물 가이드 > CONVENTIONS 순으로 따른다.

## 1. 서술

- 현재형 한다체: `You walk to the door.` → `당신은 문으로 걸어간다.` 원문이 과거형일 때만 과거형을 쓴다(회상, 전설 그림 이야기 등).
- 플레이어는 "당신". 서술에 "너", "그대", "플레이어"를 쓰지 않는다.
- 영어 대명사를 일일이 옮기지 않는다. 한국어에서 어색하면 대명사 위젯을 생략하거나, 이름 있는 인물이면 이름으로 받는다.

## 2. 선택지 (링크 표시)

- "~한다" 꼴: `[[Leave|…]]` → `[[떠난다|…]]`. 명사형 "~하기"는 쓰지 않는다(디버그 화면만 예외).
- 자주 나오는 문구의 표준(GLOSSARY-system.md §14):
  Next 다음 / Leave 떠난다(방이나 문 밖으로 나갈 때는 나간다) / Refuse·Decline 거절한다 / Ignore 무시한다 / Fight 싸운다 / Accept 수락한다 / Resist 저항한다 / Run 도망친다 / Continue 계속한다 / Remain silent 침묵한다 / Endure 견딘다 / Struggle 발버둥친다 / Submit·Give in 굴복한다 / Obey 복종한다 / Seduce 유혹한다 / Flirt 추파를 던진다 / Tease 놀린다 / Stop 그만둔다 / Step away 물러선다 / Take it 가져간다 / Back 뒤로 / Sleep 잔다 / Everything fades to black... 모든 것이 어둠 속으로 사라진다...
- 대답: Yes 예 / No 아니요.
- 시간·비용 표기 `(0:10)`, `(£5)`는 그대로 둔다.

## 3. 대사

- 직선 큰따옴표 `"`만 쓴다.
- 대사 뒤에 화자와 "말한다" 꼴이 이어지면 대사는 마침표로 끝낸다(쉼표를 쓰지 않는다): `"Let's go home," Robin says.` → `"집에 가자." 로빈이 말한다.` 물음표·느낌표는 원문대로.
- 말줄임표는 `...`(세 점), 말이 끊기면 `—`.
- 말더듬은 첫 음절을 반복하고 하이픈으로 잇는다: `"Th-thank you."` → `"고-고마워."` 자모형(ㄱ-고마워)이나 쉼표형(고, 고마워)은 쓰지 않는다. 원문에 더듬기가 있는 곳에만 쓴다.
- 인물별 화계, 1인칭, 호칭, 어미는 `characters/<이름>.md`를 따른다. PC의 말은 `characters/_PC.md`, 이름 없는 인물의 말은 `characters/_GENERIC.md`.
- 한 따옴표 안에서 화계(반말/해요체/합쇼체)를 섞지 않는다. 같은 인물, 같은 상대, 같은 장면이면 같은 화계를 유지한다.

## 4. 시스템 문구

- 설정, 도움말(tip), 안내·경고, 업적, 저널, 사이드바 상태 문구, 치트 화면은 합쇼체(`~합니다`, `~하십시오`).
- 세계의 상태 묘사(날씨, 장소 묘사)와 social 화면의 인물 상태 설명은 한다체.
- 새 문구가 들어가는 파일에 이미 정해진 말투가 있으면 그 파일의 말투를 따른다(GLOSSARY-system.md §0).

## 5. 조사 마커

- 받침에 따라 바뀌는 조사는 매크로·변수 바로 뒤에 마커로 적는다: `【은는】 【이가】 【을를】 【와과】 【으로로】 【아야】 【이나나】 【이】 【이었였】`. 마커 앞에 공백을 두지 않는다.
- 한글로 끝나는 고정 낱말 뒤에는 마커를 쓰지 않고 조사를 직접 쓴다. `<<his>>`, `<<hes>>`처럼 조사를 이미 포함한 위젯 뒤에는 마커를 붙이지 않는다(CONVENTIONS.md §1).

## 6. 고유 명사

- `GLOSSARY-propernouns.md`의 표준 표기만 쓴다. 표에 없으면 KR-old에서 기존 표기를 찾아 그대로 쓴다. 새 고유 명사는 같은 무리의 꼴을 따른다.
- 거리 이름은 "○○ 가"(하이 가, 엘크 가, 하베스트 가, 다뉴브 가, 나이팅게일 가 …). "거리", "스트리트"를 붙이지 않는다.
- 예: 하퍼 의사(하퍼 박사·닥터 하퍼 아님), 제퍼(제피르 아님), 캐스, 상아의 원혼, 거대 매, 검은 늑대, 신전, 고아원, 감옥, 황야, 술집, 쇼핑센터, 발렌타인데이, 입문자.

## 7. 표기와 맞춤법

- 통화는 `£` 기호를 그대로 쓴다("파운드"로 풀지 않는다).
- 돼요(되요 아님), 아니요(대답), 한 번(횟수), 금세, 할게.
- 의상·물건·생물 이름 등 변수 값은 번역해 넣지 않는다(CONVENTIONS.md §3, §4).

## 8. 수위와 어휘

- 원문의 노골적인 수위를 그대로 따른다. 더 순화하거나 더 거칠게 만들지 않는다.
- 몸과 성행위, 욕설의 낱말은 `GLOSSARY-body-combat.md`의 표준을 쓴다. 일반 명사는 `GLOSSARY-world.md`, 시스템 용어는 `GLOSSARY-system.md`.
